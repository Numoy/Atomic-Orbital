# Pause and interruption recovery — 2026-10-23

The bottom-right pause button freezes the current run and opens a matching arcade panel with Resume, sound and End run controls. Escape/P or Android Back toggle pause; Back/Escape still return to the menu from results. App interruptions leave the run paused after returning, so hazards cannot advance before the player selects Resume.

The existing engine pause state preserves the run, clears held input and resets accumulated simulation time. The screen also resets its ticker timestamp on pause/resume. Pause controls sit outside the gameplay pointer listener so touching them cannot start a run or accelerate the player. Sound stays stopped while paused, including when unmuted. End run returns to the menu without recording a completed game. Gameplay rules and the fixed visible field are unchanged.

The panel reuses the existing play button and utility controls, supports keyboard focus and large text, and blocks background gameplay semantics. Text-rendering errors keep their recovery action accessible.
